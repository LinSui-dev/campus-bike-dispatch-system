# 运行说明

本系统为本地可运行的软件仿真原型，运行环境为 Python 3.12+ 与 Node 20+。

## 1 环境

- Python：项目基线 3.12；本机集成环境实测 3.13.5（锁依赖在 3.13 下安装运行正常）。
- Node：项目基线 20；本机集成环境实测 24.13.0。
- 依赖锁：`backend/requirements-lock.txt`、`frontend/package-lock.json`。

## 2 安装

在仓库根目录执行（PowerShell）：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements-lock.txt
npm --prefix frontend ci
```

## 3 启动后端

默认使用 fixture 数据；正式校园数据使用 `DATA_PROFILE=campus` 并指定独立数据库：

```powershell
# fixture（虚拟夹具）
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --port 8000

# campus（正式校园数据，独立临时库）
$env:DATA_PROFILE = 'campus'
$env:DATABASE_URL = 'sqlite:///' + (Join-Path $env:TEMP 'campus.db').Replace('\','/')
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

API 文档：http://localhost:8000/docs

## 4 启动前端

```powershell
cd frontend
npm ci
# 关闭 Mock、连接后端
$env:VITE_USE_MOCK = 'false'
$env:BACKEND_URL = 'http://127.0.0.1:8000'
npm run dev
```

页面：http://localhost:5173

## 5 检查

```powershell
python scripts/check_baseline.py                    # 基线
.\.venv\Scripts\python.exe -m pytest backend/tests tests/integration   # 单元与集成
.\.venv\Scripts\python.exe -m pytest tests/acceptance -m acceptance     # 业务验收
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check.ps1  # 常规门禁
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check.ps1 -Acceptance  # 正式门禁
```

## 6 复现正式实验（120组）

以 campus profile 启动后端后，提交 `docs/integration/results/evidence/experiments/batch-120-request.json` 到 `POST /api/v1/batches`，或通过前端实验分析页面发起批量；结果见 `batch-120-result.json`。

## 7 停止

在对应终端 Ctrl+C 停止服务；正在运行的未完成实验不保存，异常实验不恢复。

## 8 文档交付

- 论文：`docs/deliverables/source/论文.docx`（可编辑源）、`final/论文.pdf`（渲染核验）。
- 答辩PPT：`docs/deliverables/source/答辩PPT.pptx`（可编辑源）、`final/答辩PPT.pdf`。
- 生成脚本：`docs/deliverables/tools/build_figures.py`、`build_paper.py`、`build_ppt.py`。
