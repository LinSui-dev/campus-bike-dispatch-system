# 系统总体设计

Vue经REST发命令、WS收完整状态；API负责校验，运行管理器独占引擎；引擎同步step；调度纯计算；NetworkX服务提供距离和路线；SQLite保存配置和被明确保存的结果。引擎不依赖HTTP/ORM，DTO为JSON兼容数据，公开签名见contracts/python_interfaces.py。

创建运行时只将active站点纳入快照、库存总量和OD；OD引用inactive站点拒绝，不能静默过滤请求。没有active站点拒绝NO_ACTIVE_STATIONS；有站但总车数为0合法，利用率null。历史保留本次实际参与站点。

## 单运行槽

全局mode为idle/interactive/batch。创建交互或批量原子占槽，暂停仍占槽，批量组合间仍占槽。冲突409 BUSY。非idle禁止结构配置CRUD，历史查询可用。批量不接受手动调度或交互控制。单进程单worker部署，不能使用多uvicorn worker绕过锁。

A用后台工作者推进同步step；API命令和step进入同一锁/队列。B组织批量，注入A的run_once执行；不单独创建无限制运行。CPU执行不能持续堵塞API事件循环。运行管理器唯一修改引擎。

## 保存

run_id创建即分配，运行态留内存，不立即写simulation_runs。正常完成和stop保存；reset(save=true)保存部分结果，false舍弃。异常本次不写历史，finally释放槽。保存失败保留内存结果进入待处理状态，不允许新运行覆盖，用户可重试stop或reset，也可明确舍弃。已完成结果reset不重复保存。

## 版本与恢复

快照保存contract/engine/generator/network版本、Python版本、完整路网站点OD参数、种子及控制命令。倍速仅影响墙钟，耗时和created_at不参与复现比较。WS seq每run单调；重连先连接并缓冲消息，再GET快照，只应用更大的seq；不假设先GET再订阅不会漏消息。重启自然idle，不恢复异常实验。
