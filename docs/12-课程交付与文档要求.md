# 课程交付与文档要求

原始依据为项目要求.png及附件2：论文版面示例.doc（该文件正文题头为附件3，不修改原件）。选择方案B：软件仿真或平台原型。

论文不少于30页，包含场景需求、总体架构、功能设计、技术选型理由、实现与测试、总结展望。PPT每页标页码与讲述人，并含成员贡献及评分表（满分100），由真实贡献填写。论文与PPT压缩包命名“智能交通专题-组号-项目名称”。源代码与运行说明作为配套交付，不把它误说成截图中额外强制要求。

题目华文中宋三号加粗；作者楷体小四；单位宋体小四；摘要不超过200字，关键词3～8个；正文宋体小四，通常1.25倍行距。一级标题黑体小三，段前后1行；二级黑体四号，段前后0.5行；三级黑体小四。原件局部正文标注1倍行距，制作论文时以实际模板核对。正式交付需渲染核查分页字体图表，当前仅提取要求，未制作论文。

F收集各开发成员技术素材与E验证证据后成文；图表必须来自实际运行，fixture截图标为联调。需求假设、地图来源与授权状态、道路长度依据、合成数据及模型局限必须说明。不得预填实验结论、测试通过数或贡献评分。
