# 验收矩阵与完成标准

## 使用规则

FR来自01，T来自09，AC是本文件可执行验收项。A/B/C/D各自实现和单元自测，E在真实集成环境复验，F提供文档和课程核验。每个AC必须写前置数据、步骤、预期、实际、证据及版本。当前矩阵是待执行标准，不是通过记录。

模块级可用明确标识的替身，不能据此勾选系统完成；系统层使用真实Engine/DispatchService/NetworkService、临时DB或隔离测试库、真实API与前端，关闭Mock。正式数据与实验额外使用campus。人工项也必须留可复现步骤与截图，不能只写“看起来正常”。
