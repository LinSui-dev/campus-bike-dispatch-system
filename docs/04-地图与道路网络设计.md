# 地图与道路网络设计

## 正式数据

D负责组织校园手绘素材、2.5D底图、路网、14站（主11/东3）、八场景OD及来源说明，放data/campus。唯一跨校区连接为主校区南门—上园村路—东校区小西门，双向。家属区、学苑公寓只背景。不能用AI图或透视像素当实测距离。

上北下南、低饱和中文底图、建议宽≥4096px。Leaflet CRS.Simple，x右y下，转换[H-y,x]；底图、默认隐藏道路、动态站点、任务路线四层，不旋转。length_m来自独立测量或核验。fixture是4站虚拟小图，不满足正式校园验收。

## 图与投影

NetworkX加权无向图，road_network.schema.json为格式权威。边长>0，不自环，端点存在，polyline首尾等于节点坐标。cross_campus标记唯一连接链，所有默认站可达。

road_offset是沿from→to折线累计像素长度的比例[0,1]，实际米长按该比例分摊。站点同边按(offset,id)拆边，偏移0/1复用端点，同位置共用节点，可产生零距离。内部拆边不改变持久化road_edge_id。路径按行进方向输出原始图像坐标折线，不能画站间直线替代。

拖动由validate_station选择最近可骑行道路并投影，返回标准化Station。默认snap_tolerance_px=40，可在正式metadata调整。图外或超容差拒绝；不可达拒绝，不能跨背景接入。A结构变更后重建NetworkService和缓存。构造接收network与stations，不查询DB。route不可达抛UNREACHABLE，站点非法抛INVALID_STATION，错误类型见公开端口。

validate_station输入为完整StationCreate，不要求调用方预知road_edge_id/road_offset。新增与PATCH都遵循07中的A→D→A流程。输入id等于现有站点时按替换位置校验，忽略该站旧接入点；服务不保存新值，只有A保存后重建实例。业务字段校验由A完成，D的错误通过A映射为400 INVALID_STATION或UNREACHABLE；Schema错误422。

默认主11站、东3站共14站，总容量565、初始290（经用户确认，见D提案与E口径结论）。OD可合成但须记录依据，不声称真实运营。来源、授权、测距依据未知处必须如实注明。
