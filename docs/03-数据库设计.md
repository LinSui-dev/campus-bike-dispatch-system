# 数据库设计

SQLite+SQLAlchemy，启用外键。默认backend/var/app.db，DATABASE_URL可覆盖。初次启动从DATA_PROFILE=fixture/campus幂等导入，重启不覆盖编辑；campus缺素材明确报错，不偷偷退回夹具。

|表|字段|
|---|---|
|stations|id PK,name,campus,zone,x,y,capacity,initial_stock,road_edge_id,road_offset,active|
|scenarios|id PK,name,start_minute,duration_min,description,is_preset|
|od_demands|id PK,scenario_id FK,origin_id FK,destination_id FK,rate_per_min,periods_json|
|simulation_configs|id PK,name,scenario_id FK,params_json,seed,algorithm|
|simulation_runs|id PK,batch_id nullable,config_snapshot_json,algorithm,seed,status,created_at,ended_at,summary_json,commands_json|
|simulation_metrics|id PK,run_id FK,sim_time_sec,metrics_json,station_states_json|
|dispatch_tasks|id PK,run_id FK,source_id,destination_id,quantity,distance_m,route_json,depart_sec,arrival_sec,status|
|batches|id PK,request_json,created_at,ended_at,status,items_json,aggregates_json|

库存容量整数、capacity>0、0≤initial_stock≤capacity；OD不同起终点且都active，率和倍率非负，时段相对场景起点的分钟半开区间不重叠。同场景同OD唯一；metrics(run_id,sim_time_sec)唯一。历史站点ID来自快照，不引用当前stations外键。

删除站点时未确认清理关联OD返回409 RELATED_OD；clear_related_od=true时事务内清理OD再删。被config引用的场景删除409 IN_USE。预设场景可编辑不可删除（409 PRESET_SCENARIO），可复制成自定义。

## 结果事务

运行、指标、任务、命令一次事务保存。历史status只有completed/stopped。异常不新增aborted运行记录。保存失败回滚并保留内存供重试，不假装成功；reset舍弃可直接释放。快照含完整运行路网，当前站点删除不影响历史。

批量每个成功子运行单独提交，结束时写批次汇总。失败item有error、run_id=null，不写不完整run；继续其他组合。进程异常不追加记录，之前已提交的子运行保留且快照含批次请求，可按batch_id识别。GET batches无汇总时可从已提交子运行恢复只读的interrupted摘要，不自动继续实验。
