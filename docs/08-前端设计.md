# 前端设计

Vue3、TypeScript、Vite、Element Plus、Pinia、Leaflet、ECharts。中文浅色桌面界面，左导航、顶部全局运行控制。页面切换不停后端；初次GET runtime，不能自动POST runs。骨架仅验证依赖与数据通路。

|页面|内容|
|---|---|
|运营总览|指标、地图、站点库存预警、借还趋势|
|停车点管理|列表地图联动、CRUD拖动、校区筛选、删除关联确认|
|仿真控制|场景CRUD、OD矩阵倍率、配置、六项运行控制|
|智能调度|算法参数、供需、手动触发、任务路线与进度|
|实验分析|历史、批量配置进度、策略对照图、有效n和标准差|

Pinia分runtime/config/history。paused也占槽，非idle禁结构编辑和新实验。重置三选项：保存并重置、舍弃并重置、取消；取消不发请求。stop说明保存当前结果；保存失败可重试，不能直接清空UI。批量不提供暂停手动调度。

刷新恢复必须按07的runtime→WS缓冲→State流程，顶部场景、当地时刻、种子、参数来自State.context，倍速使用current_speed而非冻结的params.speed。新增站点发送StationCreate，拖动发送StationPatch的x/y；不得发送或自行推算road_edge_id/road_offset。收到标准化Station后再固定标记位置。

请求期间禁重复按钮，创建与调度保留request_id供重试。501展示尚未实现；错误提示message；WS恢复按02缓冲与seq，轮询降级。图表空数据为暂无数据，null不当0，不伪造实验值。

地图只在组件边界转换[H-y,x]，道路默认隐藏，空站红、满载橙、正常蓝绿并附文字。任务按sim_time沿折线累计长度插值，不能用墙钟继续暂停动画，不修改库存。显示骑行、等待、运输未完成量。Mock显式开启并显示虚拟联调模式，正式验收禁Mock。无P1/P2入口。
