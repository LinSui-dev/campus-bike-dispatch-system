# 校园 2.5D 底图

在浏览器打开同目录的 map-preview.html，可拖动、缩放查看双校区可编辑版，右上角可切换前期局部样稿。全图是 campus-map.svg，内含功能区、校外道路、校内道路、运动场、建筑和校门图层。

生成前在个人虚拟环境安装 Shapely 2.2.0，然后运行 python data/campus/render_editable_map.py。脚本同时生成默认标签版与放大标签版。

依据北交大招生办公室 2025 年报考指南第 18 页，在统一画布上按相对位置选绘建筑。楼体采用规则体块和近似色，表面尺寸、楼高及路宽经过概化。暂无把握的建筑名称留空。直接编辑 SVG 后请同步生成脚本，否则重新生成会覆盖修改。

## 核对与限制

- 建筑与道路以手绘原图为绘制依据，未做实地测绘或地理坐标校准。
- 用户已确认原图“东校区西门”对应项目“小西门”。全图和局部样稿统一标作“东校区小西门”。
- 站点、骑行路网、米制边长及 AC-D03 验收待完成。

## 道路与建筑校核

道路和建筑共用原图描摹画布。先绘制道路边界及校内中心线，再按原图读取的宽深比例生成封闭体块。密集处在源锚点附近缩放和偏移，生成器用投影外轮廓检查建筑之间及道路边缘的净距。完整名称在放大视图显示。几何距离单位为绘图坐标，楼体宽深与位置未用实地米数校准。百度地图公开 POI 仅交叉核对思源东楼、思源西楼和教学楼名称，未取得可验证的建筑轮廓或道路坐标。

## 主校区在线地图校正

主校区参考 [OpenStreetMap contributors](https://www.openstreetmap.org/copyright) 的公开地图数据，2026-11-26 拉取。以 11 处同名建筑拟合到现有绘图坐标。调整运输设备教学馆、八教、20 号楼、思源东楼与科学会堂，参考楼体轮廓细分嘉园与逸夫楼周边建筑。道路保留学校现场已确认的项目连接，部分主干道采用在线中心线走向并与现有图面衔接。世纪钟和用户圈注的南门校徽分开标示。图面几何是对齐后的示意，在线数据不证明当前通行状态或正式骑行路网边长。

## 项目路线预览

全图青绿色线依次连接主校区南门、向南出门段、向东转弯、上园村路和东校区小西门。东小门、东门及东校区南门保留位置参照。主校区中西部保留一条代表性横接，世纪钟周边只展示连续绕行线，省略部分重复的楼间短路。东校区保留小西门进校横接、纵向主路和南部横接，省略三条北东侧楼间线。楼名放大后显示。

南门外向东转弯位置、与上园村路的过街点及小西门门前接入均需现场确认，米制长度尚无测距依据。当前仓库的正式 campus 站点及路网 JSON 尚缺，fixture 为虚拟数据。预览线只表达已确认的走法，正式站点可达与反向路径待实际路网建成后核验。

## 站点、场景和数据包审阅

站点使用地图预览的「已选站点」图层，位置已由用户确认。scenario-review.html 展示四组明示为合成的需求数据。profile-review 子目录包含 PNG 底图与统一坐标下的路网、站点、场景和配置，状态仍为 draft，待 E 协调 14 站及校区分布。正式启动使用的文件尚未放到 campus 根目录。

生成审阅 PNG 使用 data/campus/render_profile_png.ps1，随后运行 data/campus/build_profile_review.py 组装数据。几何变更时，依次重生成候选图、SVG、边长、站点、PNG 和审阅包。

## 边长口径图层

在 map-preview.html 点击「边长口径」，可按来源查看 109 条图边。单边选择器显示真实用户输入、跨区分摊、OSM 中心线量算及底图比例估算。高度放大时仍可查看底图楼名，选中边使用红线。边长或候选图更新后运行 python data/campus/build_length_preview.py 重生成 road-length-preview.js。
